# MusicHub AI v1.0 — Commercial Cloudflare Release

## Goal
Production-oriented SaaS release focused on user self-service, durable usage analytics, scheduled maintenance, automated deployment, and operational observability.

## Added
- User Dashboard at `/dashboard`.
- `/api/usage` for account, subscription, credit ledger and generation history.
- Durable `UsageEvent` records plus optional Cloudflare Analytics Engine datapoints.
- `CreditGrant` ledger for idempotent subscription entitlement accounting.
- `ProviderCostSnapshot` for historical provider cost tracking.
- `Alert` model and admin alert API.
- Scheduled maintenance endpoint for expired email-code and old audit-log cleanup.
- Cloudflare Worker observability enabled.
- Daily Cloudflare Cron trigger.
- GitHub Actions deployment workflow.
- Production preflight/deploy scripts retained and consolidated.

## Cloudflare architecture
Workers/OpenNext + Hyperdrive/PostgreSQL + Queues + R2 + KV + Analytics Engine. Cloudflare documents Hyperdrive as the path for existing PostgreSQL/MySQL databases and Queues for background processing; R2 is directly bindable from Workers. See the official Cloudflare docs for current configuration details.

## Important
The project does not claim to have deployed into the user's Cloudflare account. Deployment requires the user's Cloudflare credentials, resource IDs and secrets.

## Recommended production secrets
DATABASE_URL, HYPERDRIVE_ID, CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_API_TOKEN, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, ELEVENLABS_API_KEY, RESEND_API_KEY, CRON_SECRET and the configured application secrets.
