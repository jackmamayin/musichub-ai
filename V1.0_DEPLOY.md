# MusicHub AI v1.0 — Production Deploy

1. `npm ci`
2. Create/verify Hyperdrive for PostgreSQL and set `HYPERDRIVE` in `wrangler.jsonc`.
3. Create R2 buckets and KV namespace IDs; replace placeholders in Wrangler config.
4. Create the generation Queue and consumer/DLQ according to your v0.8/v0.9 setup.
5. Configure Worker secrets with `wrangler secret put ...`.
6. Run database migrations against the production database: `npx prisma migrate deploy`.
7. Run `npm run cf:preflight`.
8. Run `npm run cf:deploy:production`.
9. Configure GitHub repository secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` to enable automatic main-branch deployment.
10. Bind a custom domain in Cloudflare and test `/api/health`, `/pricing`, `/dashboard` and Stripe webhook delivery.

Cloudflare's current documentation recommends vinext for new Next.js Workers projects, while OpenNext remains the supported path for maintaining an existing OpenNext application. This v1.0 release intentionally keeps OpenNext to minimize migration risk from v0.9.
