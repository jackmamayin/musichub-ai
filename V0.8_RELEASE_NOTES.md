# MusicHub AI v0.8

## Main change
Generation jobs no longer require BullMQ + Redis. The web Worker publishes to Cloudflare Queues and a dedicated Cloudflare consumer Worker invokes the protected generation processor.

## Cloudflare-native services
- Workers / OpenNext
- Queues + dead-letter queue
- R2 native binding
- Workers KV rate limiting
- Service binding between app and queue consumer

## Kept from v0.7
- Stripe checkout/subscriptions/webhooks
- ElevenLabs provider adapter
- Prisma/PostgreSQL data model
- Admin profit center
- 50% margin protection
- Resend email
- SEO/legal pages
